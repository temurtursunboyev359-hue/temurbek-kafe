# Temurbek Kafe — sayt va admin panel

## Fayllar
- `index.html` — mijozlar ko‘radigan sayt.
- `admin.html` — admin panel.
- `style.css`, `app.js` — sayt dizayni va funksiyalari.
- `admin.css`, `admin.js` — admin panel dizayni va boshqaruvi.

## Ishga tushirish
1. ZIP faylni kompyuteringizga oching.
2. `index.html` faylini brauzerda ochib saytni ko‘ring.
3. `admin.html` faylini oching.
4. Namuna login: `admin`
5. Namuna parol: `admin123`

## Muhim xavfsizlik eslatmasi
Bu — ishlaydigan mahalliy namuna/prototip. Taomlar, sozlamalar va buyurtmalar brauzerning `localStorage` xotirasida saqlanadi. Shu sababli:
- Ma’lumotlar faqat o‘sha brauzer va qurilmada ko‘rinadi.
- Bu demo login internetga chiqarish uchun xavfsiz emas.
- Haqiqiy internet saytida admin loginini server tomonidagi autentifikatsiya bilan almashtirish kerak.
- Turli qurilmalarda umumiy menyu va buyurtmalar ko‘rinishi uchun Supabase/Firebase kabi backend va ma’lumotlar bazasini ulash kerak.
- Telegram buyurtmalari uchun haqiqiy Telegram manzili/botini sozlash kerak.
- Namuna narxlarini kafe tasdiqlagan narxlarga almashtiring.
- Rasmlar internet orqali yuklanadi, shuning uchun internet kerak.

## Tavsiya etiladigan keyingi qadam
Saytni AI sayt yaratuvchi dasturga yoki hostingga yuklang, keyin xavfsiz autentifikatsiya va ma’lumotlar bazasini ulang. Demo parolni haqiqiy himoya deb hisoblamang.
